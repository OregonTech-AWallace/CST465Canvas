# Caching
Caching is a technique that stores frequently accessed data in a temporary storage location.

## Reasons for Caching
- To speed up responses from your application
- To reduce load on back-end services
- To allow for a higher volume of traffic

## Types of Caching
Caching on the web falls into two main categories:
- **Client-side caching** - caching that occurs in the web browser
- **Server-side caching** - caching that occurs prior to data arriving at the web browser
