## Setup
1. Create a new web project
1. Set your project up to run MVC and add a layout file
1. Add two controllers: HomeController and AdminController
1. Add Identity to your project
1. Add the _LoginPartial to your layout file
1. Add a view for your Home controller Index action
1. Create a new action on the Home controller and make it require authorization
1. Make all actions on the AdminController require authorization
1. Verify that you can create an account/login and that your authorization checks work

## The Rest
Implement functionality in AdminController for creating/listing roles and adding users to a role. You can separate things out into as many actions/views/models as you like
